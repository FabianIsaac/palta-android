# Food Logging Specification (Delta)

## ADDED Requirements

### Requirement: Historical Nutrition Records Import from Health Connect
The system SHALL allow users to manually import past nutrition records from Android Health Connect within a user-selected time window (last 7 or 30 days), skipping entries generated by the app itself and avoiding duplicates of already imported records.

#### Scenario: Importing nutrition records from external apps within the last 7 days
- **GIVEN** the user has logged meals in an external app synced to Health Connect over the past 5 days
- **WHEN** the user navigates to Settings and initiates "Importar historial" for the last 7 days
- **THEN** the system SHALL read all external `NutritionRecord`s, categorize them appropriately into Chilean meal categories, persist them in the local database, and display the total number of imported meals

#### Scenario: Deduplication of already imported records
- **GIVEN** a nutrition record from Health Connect that was already imported into the local database
- **WHEN** the user triggers the historical import again
- **THEN** the system SHALL identify the existing record ID, skip re-inserting the record, and only count new meals

#### Scenario: Skipping own app's synced records
- **GIVEN** nutrition records present in Health Connect that were originally exported by this application
- **WHEN** the user executes the import process
- **THEN** the system SHALL filter out records matching the application's package name and avoid creating duplicate local meal entries
